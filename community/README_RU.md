# Локальный тестовый приёмник отчётов ARES

Это тестовый сервер для разработки клиента. Он слушает только `127.0.0.1:8766`, сохраняет принятые отфильтрованные отчёты в `community/data/ares_reports.sqlite3` и не получает исходные сейвы. Запуск: `Запустить_Сервер_Сообщества.bat`. Остановка: `Ctrl+C`.

В Companion задайте адрес `http://127.0.0.1:8766/api/v1/reports` и отдельно включите отправку. По умолчанию согласие выключено, а поле URL пустое. Отчёт включает режим партии и наличие сохранённого маркера `ares_ai_companion_v1`; приёмник сохраняет отчёты, но не обучает модель.

Сервер намеренно не настроен для публичного Интернета: он доступен только на этом компьютере, у него нет TLS, учётных записей, ограничений частоты запросов и публичной политики хранения/удаления данных. Не открывайте порт наружу. Для сообщества понадобится отдельно развернуть сервер за HTTPS, добавить защиту от спама, срок хранения, удаление данных и контакт администратора.
