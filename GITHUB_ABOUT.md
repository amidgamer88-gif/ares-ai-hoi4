# GitHub repository description

Use one of these short descriptions in the repository's **About** field.

**Русский**

Экспериментальный мод и локальное приложение для HOI4: проверяем, как скриптовые стратегии могут сделать ванильных ботов интереснее. Самообучение и интеграция с ChatGPT — цели развития, не функции v0.1. Целевая версия игры: 1.19.3.

Проект находится в процессе ранней разработки, поэтому любой вклад сообщества — более чем приветствуется.

**English**

Experimental HOI4 mod and local companion exploring ways to make vanilla bots more engaging. Scripted strategies ship in v0.1; ChatGPT integration and self-learning are future goals, not current features. Target: HOI4 1.19.3.

ARES is in early development, so community contributions are more than welcome.

**Suggested GitHub topics:** `hearts-of-iron-iv`, `hoi4`, `hoi4-mod`, `game-ai`, `paradox-mods`, `strategy-games`.
